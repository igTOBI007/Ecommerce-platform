# E-Commerce Platform

A full-stack e-commerce application built step by step with Spring Boot, PostgreSQL and React.

> Work in progress. This README grows as the project does.

## Tech Stack

**Backend**
- Java 21, Spring Boot 3
- Spring Data JPA (Hibernate), PostgreSQL
- Spring Security with JWT authentication
- Maven

**Frontend**
- React with Vite
- React Router, Axios
- Tailwind CSS

**Tools**
- Git and GitHub, Postman
- Docker and GitHub Actions (planned)

## Planned Features

- User registration and login with JWT and role-based access (user and admin)
- Product catalog with categories, search, filters, sorting and pagination
- Shopping cart, checkout and order history
- Admin dashboard for managing products, categories and orders
- API documentation with Swagger
- Live deployment
